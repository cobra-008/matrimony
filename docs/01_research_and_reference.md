## Registration Flow (Studied)

### Step 1: Profile For
- Myself | Son | Daughter | Brother | Sister | Relative | Friend
- Gender auto-set based on "for" selection

### Step 2: Basic Info
- Full Name
- Gender (confirm)
- Date of Birth (day/month/year dropdowns)

### Step 3: Contact
- Mobile number + OTP verification
- Email address

### Step 4: Religion & Community
- Religion (dropdown)
- Mother Tongue (dropdown)
- Caste / Community (dropdown, filtered by religion)
- Sub-caste (optional text field)

### Step 5: Location
- Country → State → City (cascading dropdowns)

### Step 6: Education & Career
- Highest Education
- Occupation
- Annual Income

### Step 7: Partner Preferences
- Age range, Height range, Religion, Caste preference

### Step 8: Photo + Submit
- Photo upload (optional but encouraged)
- T&C consent checkbox
- Submit → Go to matches immediately

**Key UX patterns observed:**
- Progress bar at top throughout
- Autosave between steps
- "Your profile is X% complete" gamification
- Immediate match preview shown after step 3

## Trust Signal System

### Verification Badges (observed)
1. **Phone Verified** — Mobile OTP confirmed
2. **Email Verified** — Email link confirmed
3. **ID Verified** — Government ID document uploaded + reviewed
4. **Photo Verified** — Selfie matched to profile photo
5. **Premium Member** — Paid subscriber badge

### Safety Features (observed)
- Phone number hidden by default
- "Secure Connect" for women (call routed through anonymized number)
- Profile privacy controls (hide from specific communities, hide horoscope)
- Block user feature
- Report profile feature (multiple categories)
- Safety center page with tips

---

## Membership/Premium Structure (Observed Pattern)

### Free Tier Limitations
- Can view limited profiles per day
- Cannot see contact details
- Limited interests per month
- Profile ranked lower in search results

### Premium Benefits
- Unlimited profile views
- Contact details visible
- "Premium" badge on profile
- Higher placement in search results
- Read receipts in messages
- AI match recommendations

### Assisted Service (Concierge)
- Dedicated relationship manager
- Curated match recommendations
- Background verification support

---

## Key Takeaways for Elite Tamil Matrimony

1. **Show value immediately** — match preview before registration is complete
2. **Trust is visual** — badges, verification counts, and success story numbers must be prominent
3. **Privacy is opt-in** — lock contact info by default, unlock progressively
4. **Mobile is primary** — all flows must work perfectly on phone
5. **Category navigation** — footer links to community/region pages are SEO gold and drive organic traffic
6. **Completion gamification** — profile % meter dramatically increases data quality
7. **Success stories build trust** — real stories with photos are the single best conversion tool
